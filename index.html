Own the protocol edge.

Sadr validates what crosses the client boundary and leaves buffers, text storage, and interface policy with the host application.

Broad coverage

Completion, navigation, hierarchy, formatting, rename, links, diagnostics, and semantic tokens.

Precise positions

Convert byte offsets and UTF-16 positions through any caller-owned compatible text index.

Resilient sessions

Cancellable futures, strict response validation, lifecycle control, and automatic server recovery.

Start the server.

Open a document and request language intelligence with ordinary Ruby objects.

Ruby
$ bundle add sadr

client = Sadr::Client.new(
  command: ["ruby-lsp"]
)
client.start
client.open(document)
client.completion(document.uri, position).await
